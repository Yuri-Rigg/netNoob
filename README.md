# netNoob

Hands-on notes and small C/C++ experiments for networking, systems, and security.

## Learning tracks

- [SIM / USIM authentication](sim-auth/README.md) — Day 1: a safe model of GSM and AKA-style authentication.

## Working rule

Each study session should leave a small, reviewable artifact: a note, test, experiment, or improvement. This repository contains **educational simulations**, never real subscriber credentials, carrier network traffic, or production authentication code.
